# insert-copied-row-spread

### 需求：如何在SpreadJS自定义插入复制单元格菜单项

#### 背景：

在designer中右键菜单中有插入复制单元格菜单项，用户想在SpreadJS中自定义添加此菜单项效果。

#### 实现方式：

可以在右键的上下文菜单中增加 “插入新行并粘贴” 的菜单项，然后实现对应 ”插入新行“ 、”完成粘贴” 的逻辑。
