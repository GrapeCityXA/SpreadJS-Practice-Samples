## 一、Demo 概述

本示例展示了如何使用 SpreadJS 的条件格式功能实现单元格格式的动态切换。通过一个简单的按钮交互，用户可以在普通数字格式和百分比格式之间切换数据区域的显示样式。该示例巧妙地利用了条件格式的公式规则，通过控制单元格的布尔值来触发格式变化，无需手动修改每个单元格的样式。

## 二、解决的问题

在实际业务场景中，用户经常需要在不同的数据展示格式之间切换，例如：

- 财务报表中需要在小数和百分比之间切换显示
- 数据分析时需要根据不同视角切换数据格式
- 避免手动选择大量单元格并逐个修改格式的繁琐操作
- 实现一键批量格式切换，提升用户体验

## 三、实现思路

### 3.1 条件格式公式规则

核心技术是使用 SpreadJS 的条件格式 API，通过公式规则动态控制单元格样式。实现步骤如下：

1. 在 A1 单元格设置一个布尔值作为格式切换的控制开关
2. 创建一个带有百分比格式的样式对象
3. 使用 `addFormulaRule` 方法添加条件格式规则，当 A1 单元格值为 TRUE 时应用百分比格式

```javascript
// 设置控制单元格初始值为 false
sheet.setValue(0, 0, false);

// 创建百分比格式样式
var style = new GC.Spread.Sheets.Style();
style.formatter = '0.00%';

// 添加条件格式规则：当 A1=TRUE 时，对 B2:G7 区域应用百分比格式
sheet.conditionalFormats.addFormulaRule(
    '=Sheet1!$A$1=TRUE', 
    style, 
    [new GC.Spread.Sheets.Range(1, 0, 6, 6)]
);
```

### 3.2 按钮交互逻辑

通过按钮点击事件切换 A1 单元格的布尔值，从而触发条件格式的应用或取消：

```javascript
document.getElementById('percentageBtn').addEventListener('click', function() {
    if (sheet.getValue(0, 0)) {
        // 当前为 true，切换为 false（取消百分比格式）
        sheet.setValue(0, 0, false);
        this.textContent = '切换为百分比格式';
    } else {
        // 当前为 false，切换为 true（应用百分比格式）
        sheet.setValue(0, 0, true);
        this.textContent = '还原';
    }
});
```

### 3.3 技术栈

- SpreadJS v17.0.8：核心电子表格组件
- SystemJS v0.19.22：模块加载器
- systemjs-plugin-babel v0.0.25：ES6 语法转译支持

## 五、功能特点

### 5.1 优点

- 实现简洁：仅需一个控制单元格和一条条件格式规则即可实现批量格式切换
- 性能优异：利用条件格式机制，无需遍历修改每个单元格的样式
- 易于扩展：可以轻松添加更多格式选项（如货币、日期等）或扩大应用范围
- 用户友好：一键切换，操作直观

### 5.2 局限性与扩展建议

- 控制单元格（A1）在实际应用中可能需要隐藏或保护，避免用户误操作
- 可以扩展为支持多种格式切换（如小数、百分比、货币、科学计数法等）
- 可以结合自定义工具栏或右键菜单，提供更丰富的交互方式

## 六、关键代码片段

### 条件格式规则设置

```javascript
// 定义样式
var style = new GC.Spread.Sheets.Style();
style.formatter = '0.00%';  // 百分比格式，保留两位小数

// 添加条件格式规则
// 参数1：公式条件（绝对引用 $A$1）
// 参数2：满足条件时应用的样式
// 参数3：应用范围（从第2行第1列开始，6行6列）
sheet.conditionalFormats.addFormulaRule(
    '=Sheet1!$A$1=TRUE', 
    style, 
    [new GC.Spread.Sheets.Range(1, 0, 6, 6)]
);
```
